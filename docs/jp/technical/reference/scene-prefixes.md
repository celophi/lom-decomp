# シーン名の接頭辞

[日本語ドキュメント](../../README.md) | [English](../../../en/technical/reference/scene-prefixes.md) | [シーン抽出ツール](scene-extractor.md) | [シーンのレイアウトと出現条件](../architecture/scene-layouts.md) | [ディスクの構成](disc-layout.md)

ディスク上のシーンファイルには、`WAL_B020.IMG` や `HTW_INN0.IMG` のような名前が付いています。
先頭の3文字は、そのシーンがどの土地のものかを表すコードです。
いくつか覚えておくだけで、`ANA` の中を探すのがかなり楽になります。
`HTW` はドミナの町、`WST` はリュオン街道、`DMY` はデバッグルーム、という具合です。
このページでは、そのすべてを一覧にします。

表に入る前にひとつ注意があります。
どの接頭辞がどの土地のものかは、ゲーム自身のデータから取っているので、ほぼ確かです。
一方で、文字が実際に何の略なのかは別の話です。
今のところは私の推測にすぎないので、わかったことが増えたらあとで見直していきます。
[まだわかっていないこと](#まだわかっていないこと)に挙げたものも同じです。

## シーン名の読み方

シーン名は、接頭辞、アンダースコア、4文字の接尾辞でできています。

```text
HTW_INN0.IMG
^^^ ^^^^
|   +------ 土地の中のどのシーンか
+---------- どの土地か
```

接尾辞には、ゲーム全体で統一されたルールはありません。
ドミナの `INN0` や `PUB0` のように見ればわかるものもあり、よく出てくるもの（フィールドの `FD`、部屋の `RM`、ダンジョンの `DN` など）は[ディスクの構成](disc-layout.md#フィールドマップmap)のマップの命名規則に載っています。
それ以外は部屋の番号か、まだ意味がわかっていないものです。

フォルダーは当てにしないでください。
シーンファイルは `ANA/INFO_*` と `ANA/MAPINFO` に入っていますが、フォルダーと土地は対応していません。
たとえば `INFO_BON` には、骨の城のシーンと並んでルシェイメア、マナの聖域、ドミナのシーンも入っていますし、`INFO_DRL` には `END` のシーンが80個すべて入っています。
必ずファイル名で判断してください。

`MAP/MAP0`〜`MAP/MAP4` にあるマップの背景（`HTW_ALL0.PRS`、`WAL_DN08.PRS` など）にも、同じ接頭辞が使われています。
例外はワールドマップです。
`WM` 配下のエフェクトのファイルは `DOM`、`MOR`、`MEK` のような独自のコードを使っているので、ここのものと混同しないでください。
そちらについては[WMAPエフェクトのリソース](../../../en/technical/reference/wmap-effect-resources.md)（英語）を参照してください。

## 土地の接頭辞

土地IDの順に並べています。セーブファイルの土地レコードと同じ番号です。
入口のシーンは、ワールドマップからその土地に入ったときに送られるシーンです。
シーン数は、その接頭辞を持つ `INFO_*` と `MAPINFO` のファイルをすべて数えたものです。

表だけではわかりにくい点がいくつかあります。

- **ほかの土地の接頭辞を借りている土地が2つあります。**
  果樹園の入口はマイホームのシーンのひとつ、`MHM_GDN2` です。
  土地6には地名がありませんが、ジオと同じ入口のシーン `MGC_GAT0` を指しています。
- **入口が複数あるのは奈落だけです。**
  どの土地にも入口の枠が4つあり、土地の状態によってどれを使うかが決まります。
  ほかの土地は4つとも同じシーンですが、奈落は `HEL_OS00`、`HEL_OS01`、`HEL_OS11`、もう一度 `HEL_OS00` を使います。
- **使われていないIDはリュオン街道になります。**
  ID 14、20、22、28、29、33と、34から63まではすべて `WST_EVT0` を指しています。
  何か意味があるというより、初期値のように見えます。

## 土地以外の接頭辞

| 接頭辞 | シーン数 | ファイル | 見たところの用途 |
|---|--:|---|---|
| `DMY` | 13 | `DMY_DEB0`、`DMY_WMP0`、`DMY_MENU`、`DMY_MAP1`〜`6`、`DMY_PUB0`〜`3` | "Dummy"。デバッグルーム（`DMY_DEB0`）、デバッグ用のワールドマップの部屋（`DMY_WMP0`）と、そこからワープするテスト用のマップ |
| `BTL` | 10 | `BTL_MENU`、`BTL_SMP1`〜`9` | "Battle"。`BTL_SMP1` はデバッグ用のワープメニューに "BattleSample1" として出てきます |
| `END` | 80 | `END_0000`〜`0079` | たぶん "Ending" |
| `INIT` | 1 | `INIT_MAP` | シーンID 0。ゲームの起動時に設定されるシーンです。デバッグメニューの "ToInitmap" もここに飛びます |
| `MID` | 11 | `MID_MAP0`〜`9`、`MID_MENU` | まだ見当がつきません。テキストは、ほとんどのシーンに入っている定型の文だけです |

## デバッグ用のワープメニュー

`DMY_WMP0` には開発用のワープメニューがあり、土地ごとに1項目、1ページに8項目ずつ、土地IDの順に並んでいます。
これらのコードの公式な一覧に一番近いもので、上の土地の表と一致しています。

| ID | メニューの項目 |
|---|---|
| 0〜7 | `mhm`、`htw`、`wal`、`prt`、`mon`、（空き）、`mgc`、`sea` |
| 8〜15 | `min`、`bon`、`lak`、`twr`、`wd1`、`cv1`、（空き）、`mnt` |
| 16〜23 | `hel`、`dst`、`wst`、`grb`、（空き）、`jgl`、（空き）、`drl` |
| 24〜31 | `esl`、`jul`、`snw`、`shp`、（空き）、BattleArena、`rui`、`sei` |

製品版と合わない項目が2つあります。
メニューでは `mgc` が5ではなく6に置かれていることと、29が "BattleArena" になっていることです。
どちらも[まだわかっていないこと](#まだわかっていないこと)に挙げています。

同じシーンには、ほかにもワープのページがあります。
接頭辞と接尾辞で書かれた個別のシーン（`wst bs03`、`cv1 b022`、`lak bs14` など）、Pub0〜Pub3 としての `DMY_PUB` のマップ、BattleSample1、スタッフの名前が付いた2つのマップ（FujitaMap と ShindoMap）、'Mana' という項目、Boss0〜Boss7 と BATTLE0〜BATTLE2 の項目が並んだページです。

## まだわかっていないこと

- **文字が何の略なのか。**
  「文字の意味」の列はすべて推測で、`MON`、`WST`、`DRL`、`ESL`、`SEI` などはかなり怪しいです。
  あとで見直していきます。
- **ジオの土地ID。**
  地名のテーブルではジオはID 5ですが、デバッグ用のワープメニューでは `mgc` が6にあり、5は空いています。
  ワールドマップはどちらのIDも `MGC_GAT0` に送るので、これでも決め手になりません。
- **土地29。**
  デバッグ用のワープメニューでは "BattleArena" になっていますが、製品版では初期値の `WST_EVT0` を指していて、地名のテーブルにも何も入っていません。
  削られた土地かもしれません。
- **土地33（変化したあとのルシェイメア）。**
  入口の枠はこれも初期値の `WST_EVT0` なので、変化したあとのルシェイメアには別の仕組みで入っているはずです。
  それが何かはまだ見つかっていません。
- **奈落の入口の違い。**
  土地のどの状態で `HEL_OS00`、`HEL_OS01`、`HEL_OS11` が選ばれるのか、それぞれがストーリー上で何を意味するのかは、まだわかっていません。
- **`MID` のシーン。**
  11個ありますが、まだ手がかりがありません。
- **デバッグルームのメニュー。**
  `DMY_DEB0` と、`DMY_MAP` / `DMY_PUB` のテキストのほとんどは日本語ですが、今のところどちらの文字表でもきれいに読めないので、メニューの中身はまだ読めていません。
- **残りの接尾辞。**
  わかっているのはよく出てくるものだけです。
  入口のシーンに付いている `OS00`、`EVT0`、`ALL0` などは、まだ説明がつきません。
